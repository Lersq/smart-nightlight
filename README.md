# Описание
Умный ночник, учитывающий уровень освещения вокруг себя.
# Схема
Обязательно учитывайте, что на схеме изображен полноценный модуль фоторезистора с уже распаянным резистором 10 кОм, если же у вас обычный маленький резистор, то добавьте к схеме подключения выше описанный компонент
